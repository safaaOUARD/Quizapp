# 🧠 Quiz App

## Description

Quiz App est une application Android interactive permettant aux utilisateurs de tester leurs connaissances à travers différents quiz. L'application offre une expérience complète allant de l'inscription jusqu'au suivi des résultats et de l'historique des sessions.

## Fonctionnalités principales

### 🔐 Inscription et Connexion

Les utilisateurs peuvent créer un compte personnel et se connecter de manière sécurisée afin de sauvegarder leurs résultats et leur progression.

### 👤 Avatar de bienvenue

Après la connexion, l'utilisateur est accueilli par un avatar personnalisé qui améliore l'expérience utilisateur et rend l'application plus interactive.

### 📝 Passage d'un examen (Quiz)

L'application permet de répondre à une série de questions sous forme de quiz afin d'évaluer les connaissances de l'utilisateur.

### ➕ Ajout de questions

Les utilisateurs ou administrateurs peuvent enrichir la base de données du quiz en ajoutant de nouvelles questions.

### 🎁 Questions bonus

Certaines sessions peuvent inclure des questions bonus permettant d'obtenir des points supplémentaires et d'améliorer le score final.

### 📊 Affichage des résultats

À la fin de chaque quiz, l'application affiche le score obtenu ainsi qu'un récapitulatif des performances de l'utilisateur.

### 🕒 Historique des sessions

L'utilisateur peut consulter l'historique de toutes ses sessions précédentes afin de suivre sa progression au fil du temps.

### 📈 Suivi des performances

Les résultats des différents examens sont enregistrés et peuvent être consultés ultérieurement pour analyser l'évolution des connaissances de l'utilisateur.

## Technologies utilisées

* Android Studio
* Java
* Firebase Authentication
* Firebase Realtime Database / Firestore
* Material Design
